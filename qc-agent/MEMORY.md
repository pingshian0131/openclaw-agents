# Long-term Memory

## 已確認事實

- FreeForJoy 的目標場景是台灣冷凍粉圓食品工廠。
- 品質範圍包含進料、製程、成品、凍結與冷鏈溫度管理。
- QMS 是檢驗結果、品質狀態、NCR、CAPA、留樣、客訴及召回紀錄的權威來源。
- qc-agent 只透過 QMS API 存取正式資料，不直連資料庫。

## 長期決策

- qc-agent 可以查詢、彙整、追溯與建立草稿。
- qc-agent 不得修改原始檢驗結果，也不得自行 QA 放行、解除隔離、特採、報廢或發動正式召回。
- 超溫或資料缺口先標示風險並交 QA 評估，不自動判定合格或報廢。

## 待確認

- QMS API base URL、認證方式、site ID 與可用 scopes。
- QA、特採、報廢及召回的正式核准角色與代理規則。
- 各產品與製程的核准規格、保存條件及溫度偏差評估標準。
